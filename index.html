3D Transzformációs Rendszer

Ismerd meg a kód működését részletes magyarázatokkal, majd másold ki a tiszta verziót egyetlen kattintással.

Kód Magyarázat
Változók és Alapbeállítások
// 'let': Új változó deklarálása (értéke később változhat).
// 'rx = 0': Létrehozzuk az 'rx' (rotation X) változót, kezdeti értéke 0 fok (függőleges dőléshez).
// 'ry = 0': Létrehozzuk az 'ry' (rotation Y) változót, kezdeti értéke 0 fok (vízszintes dőléshez).
let rx = 0, ry = 0;
// 'let mode = 'off'': Létrehozzuk a 'mode' nevű változót, és alapértelmezett értékként beállítjuk rajta az 'off'-ot.
let mode = 'off';
// 'document.body': Megcélozza a HTML oldal törzsét.\n// '.style.transition': Beállítja, hogy a stílusváltozások sima animációként történjenek.
document.body.style.transition = 'transform 0.05s linear';
Egérkövetés Logikája
// 'window.addEventListener': Figyelőt kapcsolunk az egész böngészőablakra a 'mousemove' eseményre.
window.addEventListener('mousemove', (e) => { if (mode !== 'mouse') return; let x = (window.innerWidth / 2 - e.clientX) / 30; let y = (e.clientY - window.innerHeight / 2) / 30; document.body.style.transform = `perspective(1000px) rotateY(${x}deg) rotateX(${y}deg)`; });
Billentyűzet Vezérlés
// 'keydown' eseményfigyelő a nyílbillentyűk kezeléséhez és a 3D szög módosításához.
window.addEventListener('keydown', (e) => { if (mode !== 'arrows') return; if (e.key === 'ArrowUp') rx += 5; else if (e.key === 'ArrowDown') rx -= 5; else if (e.key === 'ArrowLeft') ry -= 5; else if (e.key === 'ArrowRight') ry += 5; else return; document.body.style.transform = `perspective(1000px) rotateX(${rx}deg) rotateY(${ry}deg)`; e.preventDefault(); });
Konzol Parancsok (d3)
// Globális 'window.d3' függvény a módokváltáshoz közvetlenül a konzolból.
window.d3 = function(action, sub) { if (action === 'false' || action === 'off') { mode = 'off'; document.body.style.transform = 'none'; console.log('%c[3D] Forgatás kikapcsolva és alaphelyzetbe állítva!', 'color: red; font-weight: bold;'); } else if (action === 'switch' && sub === 'mouse' || action === 'mouse') { mode = 'mouse'; console.log('%c[3D] Mód: EGÉR KÖVETÉS AKTÍV', 'color: green; font-weight: bold;'); } else if (action === 'switch' && sub === 'arrows' || action === 'arrows') { mode = 'arrows'; console.log('%c[3D] Mód: NYILAS VEZÉRLÉS AKTÍV', 'color: blue; font-weight: bold;'); } else { console.log('Ismeretlen parancs! Használd ezeket:\n- d3("mouse")\n- d3("arrows")\n- d3("off")'); } }; console.log('%c3D Rendszer kész!', 'background: #222; color: #bada55; padding: 4px; font-size: 12px;');
