// ========================================== // VÁLTOZÓK ÉS ALAPBEÁLLÍTÁSOK LÉTREHOZÁSA // ========================================== // 'let': Új változó deklarálása (értéke később változhat). // 'rx = 0': Létrehozzuk az 'rx' (rotation X) változót, kezdeti értéke 0 fok (függőleges dőléshez). // 'ry = 0': Létrehozzuk az 'ry' (rotation Y) változót, kezdeti értéke 0 fok (vízszintes dőléshez). let rx = 0, ry = 0; // 'let mode = 'off'': Létrehozzuk a 'mode' nevű változót, és alapértelmezett értékként beállítjuk rajta az 'off'-ot (vagyis kezdetben minden ki van kapcsolva). let mode = 'off'; // 'document.body': Megcélozza a HTML oldal törzsét (az egész látható tartalmat). // '.style.transition': Beállítja, hogy a stílusváltozások ne hirtelen, hanem sima animációként történjenek. // '= 'transform 0.05s linear'': A transzformáció 0.05 másodpercig tartson, lineáris (egyenletes) sebességgel. document.body.style.transition = 'transform 0.05s linear'; // ========================================== // EGÉRKÖVETÉS LOGIKÁJA // ========================================== // 'window.addEventListener': Figyelőt kapcsolunk az egész böngészőablakra. // 'mousemove': Ezt az eseményt figyeljük (akkor fut le, ha az egér elmozdul). // '(e) => { ... }': Egy nyílfüggvény (arrow function), ami megkapja az egér adatait az 'e' változóban. window.addEventListener('mousemove', (e) => { // 'if (mode !== 'mouse') return;': Ha az aktuális mód NEM az egérkövetés ('mouse'), akkor azonnal kilépünk (return), így az egér mozgása nem csinál semmit. if (mode !== 'mouse') return; // 'window.innerWidth / 2': Az ablak teljes szélességének a fele (a képernyő közepe X tengelyen). // '- e.clientX': Kivonjuk ebből az egér aktuális X pozícióját. // '/ 30': Elosztjuk 30-cal, hogy a dőlés mértéke finom és ne túl vad legyen. Az eredmény az 'x' változóba kerül. let x = (window.innerWidth / 2 - e.clientX) / 30; // 'e.clientY': Az egér aktuális magassága Y tengelyen. // '- window.innerHeight / 2': Kivonjuk az ablak magasságának felét, hogy a képernyő közepe legyen a 0 pont. // '/ 30': Ezt is elosztjuk 30-cal a finomabb hatásért, és elmentjük az 'y' változóba. let y = (e.clientY - window.innerHeight / 2) / 30; // 'document.body.style.transform': Módosítjuk a body elem térbeli tulajdonságait. // 'perspective(1000px)': Adunk neki egy 3D-s térhatást (látószöget). // 'rotateY(${x}deg) rotateX(${y}deg)': Elforgatjuk a kiszámolt x és y értékek szerint fokokban (deg). document.body.style.transform = `perspective(1000px) rotateY(${x}deg) rotateX(${y}deg)`; }); // ========================================== // BILLENTYŰZET (NYILAK) LOGIKÁJA // ========================================== // Figyeljük az ablakban a billentyűk lenyomását ('keydown'). window.addEventListener('keydown', (e) => { // Ha a mód nem 'arrows' (nyilas vezérlés), akkor azonnal kilépünk, a nyilak nem fognak forgatni. if (mode !== 'arrows') return; // 'e.key': A lenyomott billentyű neve. // Ha a felfelé nyilat nyomják meg ('ArrowUp'), akkor adjunk 5-öt az rx értékéhez. if (e.key === 'ArrowUp') rx += 5; // Különben ha a lefelé nyilat ('ArrowDown'), vonjunk le 5-öt az rx-ből. else if (e.key === 'ArrowDown') rx -= 5; // Különben ha a balra nyilat ('ArrowLeft'), vonjunk le 5-öt az ry-ból. else if (e.key === 'ArrowLeft') ry -= 5; // Különben ha a jobbra nyilat ('ArrowRight'), adjunk 5-öt az ry-hoz. else if (e.key === 'ArrowRight') ry += 5; // Ha a lenyomott gomb egyik nyíl sem volt, kilépünk a függvényből. else return; // Alkalmazzuk a frissített rx és ry értékeket a 3D transzformációra. document.body.style.transform = `perspective(1000px) rotateX(${rx}deg) rotateY(${ry}deg)`; // 'e.preventDefault()': Megakadályozza a böngésző alapértelmezett dolgait (pl. hogy a nyilak lenyomására az oldal elkezdem lefelé-felfelé scrollozni). e.preventDefault(); }); // ========================================== // SAJÁT KONZOL PARANCS (d3 FÜGGVÉNY) // ========================================== // Létrehozzuk a saját globális parancsunkat a böngészőablakon belül 'window.d3' néven, ami két paramétert ('action' és 'sub') fogad. window.d3 = function(action, sub) { // Ha az első paraméter 'false' vagy 'off': if (action === 'false' || action === 'off') { mode = 'off'; // A módot átállítjuk 'off'-ra (kikapcsolva). document.body.style.transform = 'none'; // Eltüntetjük a 3D dőlést, visszaállítjuk simára az oldalt. console.log('%c[3D] Forgatás kikapcsolva és alaphelyzetbe állítva!', 'color: red; font-weight: bold;'); // a console.log a consolba való logolás azaz írás.: Piros üzenet a konzolba. } // Különben ha az action 'mouse', vagy a switch alatt 'mouse' szerepel: else if ((action === 'switch' && sub === 'mouse') || action === 'mouse') { mode = 'mouse'; // Átjátsszuk a módot egérkövetésre. console.log('%c[3D] Mód: EGÉR KÖVETÉS AKTÍV', 'color: green; font-weight: bold;'); // Zöld üzenet a konzolba. } // Különben ha az action 'arrows', vagy a switch alatt 'arrows' szerepel: else if ((action === 'switch' && sub === 'arrows') || action === 'arrows') { mode = 'arrows'; // Átjátsszuk a módot nyilas vezérlésre. console.log('%c[3D] Mód: NYILAS VEZÉRLÉS AKTÍV (kattints az oldalra!)', 'color: blue; font-weight: bold;'); // Kék üzenet a konzolba. } // Ha valami teljesen mást írt be a felhasználó: else { // Kiírjuk a helyes parancsokat hibaüzenetként. console.log('Ismeretlen parancs! Használd ezeket:\n- d3("mouse")\n- d3("arrows")\n- d3("off")'); } }; // ========================================== // ÜDVÖZLŐ ÉS INFORMÁCIÓS ÜZENETEK A KONZOLBAN // ========================================== // Stílusos (színes, sötét hátterű) bevezető szöveg kiírása a konzolba, amikor bemásolod a kódot. console.log('%c3D Rendszer kész! Írd be a konzolba:', 'background: #222; color: #bada55; padding: 4px; font-size: 12px;'); console.log(' d3("mouse") -> egérkövetés'); console.log(' d3("arrows") -> nyilas vezérlés'); console.log(' d3("off") -> kikapcsolás');
